### StopMotion defect and correction

Observed old behavior:

```text
After Service StopMotion, the Action goal remained EXECUTING, but canceled() was called.
The invalid EXECUTING -> CANCELED transition raised RCLError and terminated the Driver.
```

Observed behavior after the fix:

```text
Standard Action Cancel -> CANCELED
Service StopMotion      -> ABORTED
Driver remained running
```

The corresponding fix is commit:

```text
7e3ed13 Handle service-initiated motion stops as aborted actions
```

## Known limitations and unverified work

- IO/DO HIL was deferred by user decision.
- Observed `motion_execution_percent` remained `0.0`.
- HAR/controller source sampling time is not mapped; pose messages use ROS publication time.
- After an external Tool switch, users must call `get_active_tool` or repeat the lifecycle setup
  to refresh the cache.
- Tool 2 controller mass parameters are zero.
- The MoveL/MoveC/MoveS Base TCP contract is not completed or HIL-verified in this report.
- Unifying the YAML `tool_id` setting with controller Active Tool belongs to V0.2-03.
- The hand-eye calibration matrix is not integrated into the Driver.
- `FollowCartesianPath` is not implemented.
