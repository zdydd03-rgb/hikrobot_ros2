# hikrobot_description

No robot-specific dimensions, meshes, joint limits or kinematic chain were present in the validated SDK/test package, so this package intentionally does **not** fabricate a URDF.

Add the exact Hikrobot arm model URDF/Xacro and meshes here once the mechanical model data is available. The driver itself only assumes six rotary joints at the ROS interface boundary; names are configurable.
